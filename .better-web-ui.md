# .better-web-ui.md — Event Pro Design Context

This file is the canonical design context for Event Pro.
The `frontend-design` skill reads this file before producing any UI.

## Stack
- Framework: React 18 + TypeScript
- Build tool: Vite
- Styling: Tailwind CSS v3 (CSS variable tokens, HSL format)
- Components: shadcn/ui + Radix UI primitives
- Router: React Router v6
- Server state: TanStack Query v5
- Forms: React Hook Form + Zod

## Brand Identity
- Primary: #6366f1 — Indigo-500 — HSL(243 75% 59%)
  - Rationale: Bridges professional trust (blue) and celebration (violet)
- Primary hover: #4f46e5 — Indigo-600
- Neutral family: Stone (warm gray) — NOT Zinc, NOT Slate, NOT Gray
  - Rationale: Warmth makes the product feel human, not corporate
- Accent: none fixed at brand level (invitation surfaces may use Amber/Gold)
- Semantic colors:
  - success/confirmed: Green-700 (#15803d)
  - warning/pending: Amber-600 (#d97706)
  - destructive/declined: Red-500 (#ef4444)
  - info: Sky-500 (#0ea5e9)

## Typography
- Dashboard UI font: Plus Jakarta Sans (variable weight 300–800, Google Fonts)
  - Rationale: Geometric warmth, excellent at 12–16px, not Inter
- Invitation display font: Playfair Display (400–800, italic variants, Google Fonts)
  - Rationale: Classical, celebratory, reserved ONLY for invitation surfaces
  - NEVER use Playfair Display in the organizer dashboard
- Scale:
  - Display 1: 48px / Playfair 700 / -0.02em (invitation title)
  - H1: 30px / Plus Jakarta 700 / -0.02em (page titles)
  - H2: 24px / Plus Jakarta 600 / -0.01em (section headings)
  - H3: 20px / Plus Jakarta 600 / 0 (card titles)
  - Body: 14px / Plus Jakarta 400 / lh 1.6 (standard UI)
  - Body LG: 16px / Plus Jakarta 400 / lh 1.75 (content reading)
  - Label: 12px / Plus Jakarta 500 / 0.02em (form labels)
  - Caption: 11px / Plus Jakarta 400 / 0.02em (timestamps)

## Spacing
- Base unit: 4px (Tailwind default scale)
- Card internal padding: p-6 (24px)
- Page content padding horizontal: px-6 md:px-8 (24–32px)
- Section gaps: gap-8 (32px)
- Invitation card padding: p-10 (40px)
- Dashboard top-of-page padding: pt-8 (32px)

## Radius
- Default: 8px (--radius: 0.5rem)
- Small elements (badges, tags): 4px (rounded-sm → rounded)
- Large containers (modals, sheets): 12px
- Invitation cards: 16px (rounded-2xl)
- Pills (status badges): full (rounded-full)

## Shadows
- Cards: shadow-card (1px 3px, 5% opacity — very subtle)
- Cards hovered: shadow-card-hover (4px 6px, 7% opacity)
- Elevated (dropdowns, popovers): 10px 15px, 8% opacity
- Invitation card: 25px 50px, 25% opacity — intentionally visible

## Navigation
- Authenticated organizer: Fixed left sidebar (w-60) + top bar (h-14)
- Mobile organizer: Bottom tab bar (4 icons) + hamburger drawer
- Public invitation: No navigation at all — pure content experience

## Key Surfaces and Their Personalities

| Surface | Style Family | Density | Primary Emotion |
|---|---|---|---|
| Dashboard | Warm Professional | Medium | In control |
| Event Creation | Form-first | Medium | Productive |
| Event Overview | Data summary | Medium | Informed |
| Guest Management | Minimal Data | High | Organized |
| Task Management | Energetic Utility | Medium-High | Focused |
| Public RSVP | Expressive Invitation | Low | Welcomed |

## Anti-Patterns (never do these in Event Pro)
- Purple gradients on any organizer surface
- Playfair Display on any organizer surface
- Decorative box shadows on dashboard cards (keep it subtle)
- Generic "No items yet" empty states without CTAs
- Full-page loading spinners (use skeletons)
- Modal dialogs for simple confirmations that can be inline
- Color for decoration on organizer surfaces (color = state only)
